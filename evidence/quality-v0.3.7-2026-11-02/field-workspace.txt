The reviewed fallback, run against that same drifted pair
----------------------------------------------------------
The 0.3.7 worker step is allowed one `uv sync --frozen` attempt, and only when the toolkit's own reader
says the pair is current. On a pair this drifted the reader refuses, so the fallback would not run in
the field workspace. The fallback's own safety property was still measured on this pair, because it is
the pair the fallback exists for:

  before: sha256 uv.lock = 7a28c41f64fe2d2eed10cec003430fb12e44f7900d5ec8e5d4aab9e9ec3aed90
  /tmp/uvs/uv-0.5.0  sync --frozen --no-dev --python 3.12 --project /tmp/fieldpair --no-config -> exit 0
  /tmp/uvs/uv-0.13.6 sync --frozen --no-dev --python 3.12 --project /tmp/fieldpair --no-config -> exit 0
  after:  sha256 uv.lock = 7a28c41f64fe2d2eed10cec003430fb12e44f7900d5ec8e5d4aab9e9ec3aed90  (unchanged)

`--frozen` installs what the lock pins and never rewrites the lock — the toolkit's rule that setup must
not run `uv lock` in a managed directory holds even in the fallback. uv 0.13.6 reported
"~ research-stack-basic==0.3.6 (from file:///tmp/fieldpair)": the editable root is installed at the
version the manifest declares, not at the stale version the lock recorded.

2 entries in .venv/Lib/site-packages, plus pyproject.toml, uv.lock, src and installation.json. uv had
created the managed Python environment before it refused the lock, so the step's own artifact check
found both files it looks for — `mcp_server.py` and `.venv/Scripts/python.exe` — and recorded
"artifacts": { "verified": true, "observedCount": 2 } on a step whose status is "failed".

That combination is why the status record matters: extension/installer.js counts a step as installed
only when the workspace record says it was installed, so this step is reported "missing" with
"Not installed. The last setup attempt failed: …" rather than as installed, even though its files are
present. Verified in the code path stepStatus() (installer.js:209-235): a record holding only a failed
lastAttempt is not an installation.
