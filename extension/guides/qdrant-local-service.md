# Qdrant vector database

Planned vector-store integration.

## Setup

No reviewed installation recipe or locked image identity is implemented. Full selection does not install a database. Use current official docs for an independently managed experiment.

## First task and readiness

There is no toolkit first-use workflow yet. Review the Phase 3 design and choose ownership, storage, backup and recovery before integrating research data.

## Troubleshooting and limits

Not bundled and Planned describe the toolkit integration, not your whole machine. Diagnostics does not inspect Docker or ports. An unrelated running Qdrant does not make an unimplemented vector pipeline ready.

## Current documentation

[Current official documentation](https://qdrant.tech/documentation/quickstart/). Local onboarding reviewed on 11 October 2026. The bundled guide is a release snapshot; the official link opens the maintained source and may describe a newer version than your lock.
