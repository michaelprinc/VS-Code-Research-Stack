# VS Code Desktop

Host research files and editor integrations.

## Setup

Install VS Code Desktop separately, open a research folder and review its contents before trusting it. The declared minimum is 1.140.0; the reference GUI test uses 1.141.0 on Windows.

## First task and readiness

Use File: Open Folder, then select that folder under Components. The editor version is read from the running host. In multi-root workspaces, checks apply only to the selected folder.

## Troubleshooting and limits

Ready confirms the host runs. Remote and virtual workspaces are outside local runtime inspection; local Python must not be presented as the remote server runtime.
