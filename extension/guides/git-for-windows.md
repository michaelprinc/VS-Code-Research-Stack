# Git

Track selected research files and source changes.

## Setup

Install Git with official platform instructions. The catalog ID is historical; version checks also support other local desktop platforms. Git and GitHub account authorization are separate.

## First task and readiness

Check components resolves git the way it resolves uv — absolute `PATH` entries, then the documented install locations for the platform — refuses an executable inside the workspace, and reports the version its `--version` command returned or the categories it searched. Review git status in your research folder before deciding to initialize or commit. Exclude virtual environments, private generated data and credentials.

## Troubleshooting and limits

Ready confirms version reporting, not remote permissions. The diagnostic does not create repositories, commit, push or inspect credentials. A read-only remote request does not establish write scope.

## Current documentation

[Current official documentation](https://git-scm.com/docs/gittutorial). Local onboarding reviewed on 1 November 2026. The bundled guide is a release snapshot; the official link opens the maintained source and may describe a newer version than your lock.
