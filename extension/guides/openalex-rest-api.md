# OpenAlex

Search scholarly metadata through the authored adapter.

## Setup

Review current OpenAlex access/authentication instructions. The adapter reads OPENALEX_API_KEY from its process environment when supplied. Keep secrets out of committed configuration and readiness reports.

## First task and readiness

Request a small metadata search through the research MCP client, then inspect provider attribution and identifiers. Follow current quota rules. Local adapter presence does not prove remote access.

## Troubleshooting and limits

This external service has no local installed version and stays Not verified. Documentation moved to help.openalex.org; Latest docs points there. Review its authentication page if access is rejected. Diagnostics sends no provider requests.

## Current documentation

[Current official documentation](https://help.openalex.org/api/). Local onboarding reviewed on 11 October 2026. The bundled guide is a release snapshot; the official link opens the maintained source and may describe a newer version than your lock.
