# Semantic Scholar

Use optional Academic Graph metadata search.

## Setup

Review official API docs and applicable terms. The authored adapter requires SEMANTIC_SCHOLAR_LICENSE_ACKNOWLEDGED=true after review and can read SEMANTIC_SCHOLAR_API_KEY from its environment. That flag is not a grant of rights.

## First task and readiness

Make a small metadata query in your research MCP client after deliberate configuration. Inspect identifiers/provider attribution and distinguish metadata from available full text.

## Troubleshooting and limits

External service does not mean installed or authorized. Access keys, quotas and terms can change; consult current docs. Diagnostics makes no request and local adapter presence is not service readiness.

## Current documentation

[Current official documentation](https://api.semanticscholar.org/api-docs/). Local onboarding reviewed on 11 October 2026. The bundled guide is a release snapshot; the official link opens the maintained source and may describe a newer version than your lock.
