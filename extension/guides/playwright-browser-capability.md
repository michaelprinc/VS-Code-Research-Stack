# Playwright browser integration

Optional planned research browser capability.

## Setup

GUI-test Playwright is development tooling, not this research component. Browser automation is not wired into the toolkit. Review official MCP instructions before choosing an independent browser capability.

## First task and readiness

No research-browser workflow is implemented. Future onboarding needs a dedicated browser profile, chosen provider/session and deliberate authorization for institutional access.

## Troubleshooting and limits

Planned describes toolkit integration, not a machine-wide browser inventory. Diagnostics never launches browsers, reads profiles/cookies or downloads browsers. GUI test success is not evidence of this capability being ready.

## Current documentation

[Current official documentation](https://github.com/microsoft/playwright-mcp). Local onboarding reviewed on 11 October 2026. The bundled guide is a release snapshot; the official link opens the maintained source and may describe a newer version than your lock.
