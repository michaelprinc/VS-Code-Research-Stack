# GitHub remote MCP

Use explicitly authorized remote repository tools.

## Setup

This external service is optional. Review official remote configuration and scopes. The source repository provides a read-only repos fragment; provision access deliberately through your client.

## First task and readiness

Keep local document work functional without this service. If needed, add reviewed remote configuration and verify a read-only request. Do not infer write scope from successful read access.

## Troubleshooting and limits

External service and Not verified mean no connection or credential check was made. Confirm organization policy, endpoint access and actual scope in the client. Never paste secrets into shared readiness output.
