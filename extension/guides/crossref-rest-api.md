# Crossref

Look up DOI and bibliographic metadata.

## Setup

The adapter supports optional CROSSREF_MAILTO and CROSSREF_PLUS_API_TOKEN in its process environment. Review current access instructions before using a paid or institutional pool.

## First task and readiness

Look up one known DOI through the research MCP client. Compare title/authors/publication details to the source document and preserve the DOI and provider attribution.

## Troubleshooting and limits

Readiness remains Not verified until the client request succeeds. Report rate limits or failed lookups explicitly. Metadata access is not full-text access. The dashboard neither inspects tokens nor contacts this provider.

## Current documentation

[Current official documentation](https://www.crossref.org/documentation/retrieve-metadata/rest-api/). Local onboarding reviewed on 11 October 2026. The bundled guide is a release snapshot; the official link opens the maintained source and may describe a newer version than your lock.
