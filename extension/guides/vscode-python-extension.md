# VS Code Python extension

Select and work with project interpreters.

## Setup

Install/enable ms-python.python in the appropriate profile and host. Use Python: Select Interpreter. The MCP worker and notebook analysis interpreter can intentionally differ.

## First task and readiness

The inventory displays the editor extension's version separately from Python. Select the worker for source work or analysis environment for notebooks, then verify the selected executable.

## Troubleshooting and limits

Installed does not prove interpreter discovery, debugging or kernel execution. Check profile, enablement and remote placement if absent. Avoid global packages to repair a project-environment mismatch.
