# Research metadata adapter

Expose literature metadata and citation tools in a separate server.

## Setup

**Set up package components** installs the adapter and supplies its Research metadata/RIS MCP server. No scholarly service account is installed. The older `add-recommended` CLI overlay is optional for research skills, provider settings and notebook scaffolding; it preserves existing files.

## First task and readiness

Review the resulting configuration and start research-stack-recommended through your client. Begin with a small Crossref lookup and inspect DOI/provider/provenance fields. Metadata is not paper full text.

## Troubleshooting and limits

Ready for the adapter means real MCP discovery and local RIS preparation passed. It does not imply provider or Zotero connectivity. Scholarly API quotas, authentication and acknowledgement need separate checks; read the individual guides. Legacy module/file presence alone remains Not verified.
