## 5. What this documentation does not claim

1. **No 0.3.15 artifact exists.** Nothing was packaged, audited, installed or published. `npm run package`, `verify-package`, `check:payload` and the changelog-asset check have no 0.3.15 candidate; the `dist` file in the tree is an interim 0.3.14 candidate build whose digest does not match the audited 0.3.14 digest recorded in `.agent/QUALITY_STATE.md`, which is why `README.md` calls it an interim candidate instead of the audited artifact.
2. **No packaged page certifies the payload.** Member counts, packed/unpacked bytes, artifact digests and the payload-ceiling decision — including the raise from the 0.3.14 ceiling to the 0.3.15 ceiling and the headroom it leaves — live in `.agent/QUALITY_STATE.md` and T16-08/T16-12 of `specs/phase-16-next-release-recommendations/acceptance.md`. A page inside the archive cannot certify the archive that contains it, so `extension/CHANGELOG.md`, `MARKETPLACE-CHANGELOG.md`, `extension/README.md`, the guides and the worker README carry none of those figures.
3. **`extension/worker/bundle.json` is only partly fresh.** P7 updated `workerVersion`, `extensionVersion` and the three hashes of the files it stamped. Every other entry — the `README.md` copy and each `src/research_stack/*.py` the code packages are editing — is stale relative to the tree **by design**: the manifest is regenerated by `scripts/build_worker_bundle.py`, which the integrator runs once. `bundle.json`'s sha256 quoted in §1 is therefore a checkpoint value, not a publishable manifest.
4. **Retrieval figures are a synthetic-corpus measurement.** They compare the three modes on text authored for the purpose; the operator's own corpus was not measured and is not available on this host; `ty-01` Recall@10 0.000 and `cz-01` 0.500 are open ranking defects; `rsk-hashing-v1` is a lexical signature, not a semantic model; the ceiling-cost numbers make no ranking claim about a fixture whose chunks are identical text.
5. **No Zotero write has been made to a live Zotero 10 library.** Every Zotero statement is pinned against an emulated Zotero 10 answering with the 14 and 19 November 2026 measurements (T14-20 owed).
6. **The GitHub numbers are catalog values.** Six anonymous probes produced six 401s; there is no `tools/list` capture, so no statement here is an observation of a running GitHub MCP server or of how a Copilot client honours `mcpServers[].tools`. `verifyPresetTools` was not written (T16-05, deferred).
7. **Provider claims stop where the tests stop.** The reservation-release guard, the four consent states and the split of installation facts from provider state are pinned in code and tests; Semantic Scholar's field fill could not be measured (anonymous HTTP 429 in this container), and no claim is made about its field coverage.
8. **Five planned components are deferred, not rejected** (`specs/phase-16-next-release-recommendations/decisions-P9.md`): `qdrant-local-service`, `cpu-embedding-runtime-and-model`, `duckdb-research-record-store`, `playwright-browser-capability`, `institutional-provider-adapters`. `extension/components.json` changed only in the review date of those entries. Chromium fetched for the browser test is a build-host tool and grants no browser capability to the Toolkit.
9. **Reference-host work is still owed:** the Windows install of a 0.3.15 candidate and the four panel scenarios in a real Extension Host (T16-01), NTFS junction detection (`lstat().isSymbolicLink()` on a reparse point), the isolated-worker branch of the reading gate, a live `tools/list`, retrieval on the operator's corpus, and `T8-18` document-level claims. G1–G4 remain open and no local check closes them.
10. **Skipped tests are recorded as gaps, not passes.** Where a file-link fixture cannot be built on a host, the case skips with the reason named.
